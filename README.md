# Fantasy
Analítica personal de LaLiga Fantasy Oficial mediante scraping de futbolfantasy.com: mercado, fichas de jugador, calendario y puntuación por jornada, con sincronización a PostgreSQL (Supabase). Incluye revisión de seguridad del código (gestión de credenciales, validación de entradas, hardening de peticiones). Proyecto sin ánimo de lucro.
